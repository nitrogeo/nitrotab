# nitrotab
get a beautiful and functional new tab page on any browser and on all your devices.

## why?
this project is both 1) a good way for me to learn webdev and 2) a tool that can grow into a proper "nitrox-level" tool that fixes the problems with other new tab tools (bloat, paywalling, gui lmitations, etc).

## features 
(part 1)
- add all your favorite websites for quick access
- a beautiful built-in theme that allows for some customization

(part 2)
- sync your data via a cloud service of your choice
- a gui editor to design a page layout that works for you
- live widgets relevant to the tools you use
- sync or add your browser's custom search engines for faster access to site search
- tons of freedom regarding customization


## installation
coming soon to the Mozilla Web Store. the chromium version will most likely have to be sideloaded.
